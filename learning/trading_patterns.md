# Trading Patterns Library

Patterns synthesized from actual trading decisions. Updated via trading-decision-capture skill.

## Pattern 001: 高开分发型 (Gap-and-Trap)
- 信号：日高在开盘30分钟内形成，量能随后萎缩
- 案例：MRVL 2026-05-14（日高09:55，30分钟内见顶）
- 正确操作：观察期结束后等反弹至VWAP减仓，不追涨
- 错误操作：高点前加仓，加重平均成本

## Pattern 002: 先跌后涨型 (Dip-and-Rip)  
- 信号：开盘低开或小幅下跌，然后全天上涨创新高
- 案例：MSTR 2026-05-14（09:55日低，13:00日高+8.4%）
- 正确操作：观察期内不慌，10:00后看方向确认入场
- 关键区别：日低在前30分钟 vs 日高在前30分钟
