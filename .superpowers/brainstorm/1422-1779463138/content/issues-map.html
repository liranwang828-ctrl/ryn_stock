基于你刚才的反馈，逐一诊断根因

📋 问题清单

#1 组合刷新缺失

更新持仓后，Overview 的组合风险卡无「刷新」按钮。 根因：/api/status 不重建 portfolio_snapshot，只读已有文件。

API 缺失
#2 NAV 历史不更新

同 #1，净值 Chart.js 曲线依赖 portfolio_history， 数据源 portfolio_snapshot_{date}.json 未随持仓变化重建。

同 #1
#3 「生成」按钮含义不明

有 CIO 报告→显示 CIO 链接；无 CIO→显示「📊生成」。 但无「研报」状态指示，且按钮未说明生成内容（CIO辩论+memo）。 AMD 添加后无 CIO 报告，所以只有「生成」按钮。

UX 不清
#4 流程引导断裂

Step1(扫描)→Step2(盘前决策)之间缺「确认关注标的+批量生成报告」步骤。 且缺少「一键生成缺失的盘前报告+研报」按钮。

流程缺失
#5 盘前决策后流程卡住

SOP 状态检查用 daily_plan_{date}.json， 但 premarket_summary.py 不生成此文件 → Step2 永远「待计划」。

状态检测错误
#6 盘中详情完全无内容

盘中详情 tab 依赖 intraday_snapshot_{date}_{sym}.jsonl， 只有 poll.py 运行时才生成。盘前决策产出（macro_strategy 节点）未写入此文件。

数据链断裂
#7 CIO 脑暴不应阻塞主流程

Step3(CIO辩论)在 pipeline 顺序中，但实际不阻塞后续步骤。 CIO 产出：HTML 报告 + strategic_memo + macro_strategy 节点更新。 对盘中决策的影响：macro_strategy 节点被 premarket_summary 读取。

定位调整
#8 盘中监测无法启动

/api/run?task=poll → python agents/poll.py [自选股...] 需排查：Python 路径、缺失依赖、poll.py 本身的启动逻辑。

需排查
🎯 解决优先级建议（按你的顺序：内容→可维护性→交互）
  1. #4+#5 修复流程引导 — 补确认步骤 + 修复状态检测（最影响日常使用）
  2. #6 盘中详情数据链 — premarket_summary 产出写回 dashboard 数据文件
  3. #1+#2 组合刷新按钮 — 新增 /api/refresh-portfolio 端点
  4. #8 排查 poll 启动 — 修复盘中监测
  5. #3 生成按钮 UX — 明确状态标签 + 批量生成
  6. #7 CIO 从主流程移出 — pipeline 重排
  7. 模板拆分为模块化（可维护性）
  8. Chart.js 增强 + 交互优化
