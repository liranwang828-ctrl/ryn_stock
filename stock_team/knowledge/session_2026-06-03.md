# Session Notes - 2026-06-03

## Intraday Notes

### CRDU: leveraged order discipline failure

- Context: CRDU was held as a leveraged tool position for CRDO. Premarket/early price was high enough to justify predefined profit-taking and stop-loss orders, but the orders were canceled/removed because the price looked too high and the user wanted more upside.
- User self-review: this was too greedy. For leveraged products, high premarket strength should trigger bracket planning, not looser discipline.
- Trading judgment: the main issue was not only stock selection, but failure to pre-commit execution rules before volatility expanded.
- Rule to keep:
  - For leveraged ETFs/tools held into the open, place OCO/bracket orders before or immediately after the open if premarket has already moved strongly.
  - Use at least two brackets: one for risk recovery, one for optional extension.
  - Do not cancel a valid take-profit/stop-loss bracket just because the price looks like it may go higher.
  - If the bracket is canceled, a replacement bracket must be placed immediately; no naked leveraged exposure during the open.
- Practical template:
  - First bracket: sell part of the position into the first reasonable rebound/strength area; stop below VWAP or the first intraday failure level.
  - Second bracket: keep a smaller runner only if the underlying remains above VWAP and confirms relative strength; otherwise exit on failure.
- Lesson to keep:
  - Leveraged products should be managed by pre-committed orders, not by real-time greed.
  - A strong premarket move is a reason to define exits earlier, not a reason to remove exits.
