# 交易知识树

这份知识树回答的是：**为什么这样判断。**

它不是盘中速判卡的替代品，而是盘中规则背后的解释层。

---

## 1. 环境层

### 1.1 进攻日

特征：
- `QQQ` 稳或走强
- `VIX` 不恶化
- 高 beta 个股能回踩后修复
- 板块内部会出现强者恒强

意义：
- 更适合做 `VWAP reclaim -> 站稳 -> 再扩张`
- 更适合小仓试错
- 不必等到完全起飞才承认它强

### 1.2 防守日

特征：
- 指数弱
- 恐慌升温
- 高 beta 普遍失守
- 反弹常常只是逃命窗口

意义：
- 优先做仓位保护
- 不主动追高
- 强票也要更严格确认

### 1.3 顺风偏置

典型例子：
- 月末 / 养老金再平衡卖盘
- 比特币大跌带来的风险偏好降温

定义：
- 它不是单独交易信号
- 它只是把原本就成立的动作推得更坚定

一句话：
- **顺风偏置 = 原本该卖的更早卖，原本不该追的更别追**

## 2. 板块资金流层

### 2.1 AI 不是一个桶

AI 资金不会平均分配，而会在内部轮动：

- 软件 / 安全 / 应用层
- 光 / 存储 / 硬件链
- 电力 / 基建 / 配套层

所以不能只说“AI 强”或“AI 弱”。

### 2.2 软件 / 安全占优时

常见表现：
- `SNOW / NOW / ZS` 这类票容易回踩后继续走
- 市场偏好轻资产、纯暴露、高确认度
- 资金更愿意买“马上能讲清楚”的故事

### 2.3 光 / 存储被抽血时

常见表现：
- 板块不是全崩，而是内部先分化
- 复杂票先被减配
- 纯、轻、好解释的票比重平台票更抗跌

### 2.4 资金不是离开 AI，而是在 AI 内部换车

一句话：
- **看的是资金去哪，不只是资金离不离场**

## 3. 个股类型层

### 3.1 纯暴露票

特征：
- 逻辑清楚
- 主线映射直接
- 市场容易快速定价

优点：
- 适合短线
- 适合进攻日

风险：
- 一旦太热，容易看对买贵

### 3.2 复杂平台票

特征：
- 业务很多
- 叙事层次多
- 需要市场有耐心

优点：
- 长期可能更厚

风险：
- 风格不对时最先被减配
- 不能指望“板块一轮动就自然回来”

### 3.3 弱破位票

特征：
- 关键位失守
- 收不回去
- 反抽弱

核心任务：
- 不是证明自己多懂公司
- 而是先把低效率仓位处理掉

### 3.4 高 beta 事件票

特征：
- 财报、催化、缺口
- 波动极大
- 盘中节奏很快

核心任务：
- 不追最后一段
- 抓确认点

## 4. 执行模板层

### 4.1 模板 A：VWAP reclaim -> 站稳 -> 再扩张

适用：
- 进攻日
- 强票
- 高 beta 机会股

意义：
- 这是“由弱转强刚被确认”的那一下
- 不是最低点
- 也不是最后冲天那一刻

这是以后最重要的右侧模板之一。

### 4.2 模板 B：破位后弱拉锯

适用：
- 弱票
- 关键位失守后
- 但没有出现真正崩盘式下杀

意义：
- 不一定要一秒钟砍在最差价
- 可以给 `3-10` 分钟分歧过滤
- 让自己卖在反抽阻力，而不是卖在情绪黑洞

### 4.3 模板 C：真失控破位

特征：
- 大盘同步恶化
- 个股连续大阴
- 承接完全失效

意义：
- 这时不等
- 立刻执行

### 4.4 模板 D：高开失败

特征：
- 高开看起来很美
- 后续收不回 `VWAP`
- 强势没有延续

意义：
- 不能再按最强票看待
- 需要降级观察

## 5. 持仓周期纪律层

### 5.1 日内单

你买它，是为了今天的结构。

管理重点：
- `VWAP`
- 日内承接
- 是否继续扩张

### 5.2 波段单

你买它，是为了未来几天到几周。

管理重点：
- 能否跨日维持结构
- 叙事是否持续
- 回撤你能不能接受

### 5.3 长期 thesis

你持有它，是因为你认可商业模式和中长期位置。

管理重点：
- 行业位置
- 竞争力
- 财务质量
- 叙事是否升级或降级

### 5.4 最重要的纪律

- 日内单不要自动升级成长拿
- 想升级，必须盘后重新判断
- 不允许盘中因为喜欢一只票，就临时改合同

## 6. 案例库

### 6.1 BABA / SYM

结论：
- 方向对
- 节奏差

Lesson：
- 不是“卖错方向”
- 是“卖对方向，但卖得太急”
- 弱票处理要区分：
  - 真失控破位
  - 破位后弱拉锯

### 6.2 SNOW / NBIS / ARM

结论：
- 不是没机会
- 是没抓到确认点

Lesson：
- 真正该做的是：
  - 回踩
  - reclaim `VWAP`
  - 站稳
  - 再扩张

而不是等到最后加速才后悔。

### 6.3 IOT

结论：
- 短线交易成立
- 长期 thesis 没有自动翻案

Lesson：
- 一天的强势可以推翻“今天完全不能碰”
- 但不能自动推翻旧的中长期研究

### 6.4 COHR vs LITE

结论：
- 有时候市场不是不要这个板块
- 而是在板块内更偏好“纯、轻、干净、好解释”的票

Lesson：
- `COHR` 更复杂，容易被打复杂性折价
- `LITE` 更像纯暴露或更干净的映射
- 风格偏短线效率时，资金可能先放弃 `COHR`

### 6.5 NOW / ZS

结论：
- 强票不是因为涨了就该卖
- 要看它是否还能维持强于大盘的结构

Lesson：
- 真强票可以继续拿
- 减仓不一定因为票坏了，有时只是仓位管理

## 7. 以后怎么往里加东西

每次新增经验，只做三种动作之一：

1. 改一条速判规则
2. 在知识树上加一个节点
3. 在案例库里补一个新案例

不要把所有经验都重新写成长文章。

一句话：
- **让知识累积，而不是让复盘重复。**
