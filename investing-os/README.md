## Vision

This repository is a personal investing operating system.

It is not an automatic trading robot.

It is designed around:

- Personal cognition as the source of judgment
- AI as an amplifier
- Discipline as the execution constraint

Returns are an output. Cognitive evolution is the core objective.

## Core Principles

- Research is owned by me.
- Discipline is enforced by the system.
- AI amplifies capability.
- AI is not the decision maker.
- AI is an assistant, not a substitute for judgment.

## Daily Rhythm

- Pre-market: collect information, narrow focus, define watchlist, write plan.
- Intraday: monitor key nodes, execute plan, avoid emotional operation.
- Post-market: review decisions, validate thesis, correct cognition, update the system.

## Design Boundary

This system may collect information, calculate indicators, parse filings, organize notes, check logic, and remind discipline.

It must not make final investment decisions.

The human owns worldview, judgment, risk-bearing, and cognitive growth.
