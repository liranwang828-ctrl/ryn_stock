Active Cognitive Risks / 当前认知风险

High Risk

  • 亏损修复倾向：想通过新的风险快速修补上一笔亏损。
  • 杠杆放大错觉：认为标的逻辑正确就能承受杠杆波动。
  • 单标的绑架：一个持仓占据过多注意力与情绪。

Required Guards / 必须护栏

  • 新增风险前必须重新写 thesis、trigger、invalidation、max loss。
  • 单标的连续盯盘超过 30 分钟，进入暂停记录。
  • 止损或重大回撤后，不用短线交易修复情绪。

State Machine / 状态机解释

Green 只执行盘前批准动作。

Yellow 市场、证据或情绪偏离，新增风险需要重新确认。

Red 禁止短线新增风险，只允许降低风险、记录、复盘、等证据。

No-Trade 情绪失控或连续违规，只允许风险降低和系统复盘。

Control Summary / 盘中控制摘要

当前状态 Red

计划一致性：部分有效。核心仓仍在计划内，短线和杠杆新增风险关闭。

下一步安全动作 Wait

等待证据，记录事实。若必须处理风险，只能执行盘前已写明的减风险动作。

允许动作

  • 观察，不扩大风险。
  • 记录盘面和情绪事实。
  • 请求 QQQ / VIX / MUU / IBKR 证据。
  • 只执行预先计划过的减风险动作。

禁止动作

  • 新开短线风险。
  • 扩大杠杆暴露。
  • 为了修复亏损而摊低成本。
  • 把等待反弹当成计划。

缺失证据

  • IBKR position snapshot。
  • QQQ / VIX runtime context。
  • MU / MUU relative strength snapshot。

活跃认知风险

  • 亏损修复冲动。
  • 单标的注意力绑架。
  • 低估杠杆产品波动。
