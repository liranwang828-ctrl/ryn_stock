# Integrations

This directory defines how external projects and tools connect to `investing-os`.

Integrations should not blur project identity.

External tools may provide data, signals, calculations, or experiments. `investing-os` decides whether the output improves cognition, discipline, or risk control.

## Integration Rule

External output enters `investing-os` only after interpretation.

Raw output is not knowledge.

Signals are not commands.

Backtests are not beliefs.
