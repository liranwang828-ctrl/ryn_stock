# Weekend Review Workflow

The weekend is the main cognitive upgrade window.

Suggested time budget: 4-5 hours total.

## 1. Weekly Review

Time budget: 60 minutes.

Questions:

- What was the biggest mistake this week?
- What was the strongest judgment this week?
- Which decision was emotional?
- Which position affected life or sleep?
- Which thesis changed?
- Which signal was misunderstood?

Output:

- Journal update
- Mistake record
- Risk update

## 2. Deep Research

Time budget: 2 hours.

Choose one:

- One company deep dive
- One industry map
- One methodology study
- One historical case

Output:

- Wiki note
- Company dossier
- Thesis update

## 3. System Update

Time budget: 60 minutes.

Check:

- Did templates miss anything?
- Did an agent produce low-quality output?
- Did a risk rule fail?
- Did a signal create noise?
- Did the framework drift from WHY?

Output:

- Template update
- Checklist update
- Agent update
- Framework note

## 3A. Tactic Event Summary

Use this when a tactic, signal, or repeated behavior needs statistical review.

Request from `stock_team`:

- `templates/tactic-event-summary-request.json`

Expected packet:

- `system/data/packets/tactic-event-summary-packet.md`

Use for:

- RS pullback rebound review
- missed opportunity quality review
- false positive review
- opening 30m tactic review
- QQQ risk-off disable rule review

`stock_team` provides event statistics. `investing-os` decides whether to propose tactic, checklist, or risk-budget updates.

## 4. Next Week Plan

Time budget: 30-60 minutes.

Define:

- Research theme
- Watchlist focus
- Key holding risks
- No-trade rules
- One cognitive objective
