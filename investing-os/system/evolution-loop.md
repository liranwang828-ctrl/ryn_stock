# Evolution Loop

The system improves through repeated feedback.

```text
Trade
|
Review
|
Discover error
|
Correct cognition
|
Update framework
|
Update wiki
|
Update agents
|
Next trade
```

## Review Questions

- What did I believe?
- What happened?
- What did I do?
- What was emotional?
- What was rational?
- What evidence did I ignore?
- What part of the framework failed?
- What should be updated?

## Outputs

Each review should create one or more of:

- Journal entry
- Mistake record
- Principle update
- Template update
- Agent prompt update
- Company or industry wiki update
