# Research Report Reliability Checklist

在把研究阅读报告视为“可读且可执行”的正式产物前，先过这一张表。

目标不是让报告更花哨，而是避免最危险的逻辑混写：

- Reality 没变，却写得像公司变弱了
- 价格回落了，却写得像公司变强了
- 只是赔率变化，却写成 thesis 升级

## 1. 维度分离检查

逐段确认：这句话到底在描述什么？

- [ ] Reality：业务 / 行业事实是否变强或变弱？
- [ ] Price：市场是否把预期交易得更满或更便宜？
- [ ] Behavior：价格行为 / 趋势是否改善或恶化？
- [ ] Odds：当前下手性价比是否改善或恶化？

如果一句话同时在说两个以上维度，默认需要拆开重写。

## 2. 高点语义检查

当报告写到股价冲高或创新高时，确认没有偷换成“公司变弱”。

- [ ] 是否明确这是 Price stretch / expectation expansion，而不是 Reality 转弱？
- [ ] 是否明确高点的问题主要是赔率下降，而不是自动下结论为 thesis 变差？

## 3. 回落语义检查

当报告写到大幅回落时，确认没有偷换成“公司变强”。

- [ ] 是否明确回落首先说明 Behavior 变弱或价格重估？
- [ ] 是否只在 Reality 没坏时，才把回落解释为 Odds 可能改善？
- [ ] 是否避免把“更值得重新评估”写成“已经更强”？

## 4. 主语检查

每一个关键判断都要能回答：

- [ ] 变化的是公司 Reality？
- [ ] 变化的是行业 Reality？
- [ ] 变化的是市场定价？
- [ ] 变化的是操作赔率？

如果主语不清，这个判断不能直接进入正式报告。

## 5. 时间线解释检查

时间线允许继续使用：

- Event
- Price
- Interpretation

但 Interpretation 必须能回答“哪一个维度变了”。

- [ ] 是 Reality strengthened？
- [ ] 是 Price stretched？
- [ ] 是 Behavior weakened？
- [ ] 是 Odds improved after repricing？

如果 Interpretation 直接跳成投资建议，需要重写。

## 6. 关键价格检查

均线、VWAP、结构位、期权墙只能支持“位置判断”。

- [ ] 关键价格是否只被用来说明观察区、试探区、升级区、降级区？
- [ ] 是否避免把价格锚点直接当作“公司更好 / 更差”的证据？

## 7. Trigger 一致性检查

- [ ] Upgrade trigger 是否对应 Reality 继续验证或 behavior 修复确认？
- [ ] Downgrade trigger 是否对应 Reality 被证伪或关键结构失守？
- [ ] 是否避免把“更便宜了”直接写成 upgrade trigger？

## 8. 当前看法四分法

正式报告的“当前投资看法”段，至少应能被读成四个判断：

- [ ] Reality：当前事实强弱
- [ ] Price：当前定价状态
- [ ] Behavior：当前趋势 / 结构状态
- [ ] Odds：当前值不值得重新评估或试错

如果四个判断读不出来，这份报告还不够可靠。

## 通过标准

只有当上面 8 项都能回答“是”，这份研究报告才可以被视为：

- 可供阅读
- 可供讨论
- 可支持下一步操作思考

否则先修逻辑，再谈扩展更多公司。
