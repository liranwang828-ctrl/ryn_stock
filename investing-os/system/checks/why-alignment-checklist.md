# WHY Alignment Checklist

Use this checklist before adding major content, changing workflows, importing external output, or acting on signals.

## Core Check

- Does this serve cognitive evolution?
- Does this keep final judgment human-owned?
- Does this use AI as an amplifier, not a decision maker?
- Does this improve discipline?
- Does this reduce emotional decision-making?
- Does this respect risk first?
- Does this create durable knowledge?

## Trading Check

- Is there a written thesis?
- Is there a falsification condition?
- Is position sizing defined?
- Is downside risk clear?
- Is this action already covered by a plan?
- Would I still approve this decision after sleeping?

## Research Check

- Does this improve understanding of an industry, business model, moat, pricing power, management, financial quality, or market behavior?
- Is the output reusable?
- Should this become a wiki note, template update, or agent update?

## External Output Check

- Is this only a raw signal, or does it contain interpreted knowledge?
- What assumption does it rely on?
- What does it not prove?
- What would make it invalid?

## Decision

- Add to core
- Add to research queue
- Keep in external project
- Ignore
