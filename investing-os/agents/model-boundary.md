# Model Boundary

## Purpose

Define what lower-capability or external models may and may not do inside the investing operating system.

## Allowed Work

Lower-capability models may:

- organize raw materials
- summarize trade records
- create market data tables
- extract wiki entries
- check encoding or formatting issues
- count missing template fields
- collect historical case source material

## Forbidden Work

Lower-capability models must not:

- give final buy / sell / hold advice
- modify position rules
- modify core trading-history JSON
- assign final candidate tiers
- rewrite the user's trading philosophy
- modify hard system rules
- convert temporary context into durable principles

## Handoff Requirements

Every lower-model output must state:

- what was done
- data sources used
- uncertainty
- what requires senior review

## Review Rule

Lower-model output can become input.

It cannot become final trading judgment.
