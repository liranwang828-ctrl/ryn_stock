# Execution Post-Market

## Purpose

Hand execution experience to the evolution system.

## Required Review

- Run file growth health check with `./tools/check-file-growth.ps1` before and after absorbing durable lessons.
- What was planned?
- What happened?
- What did I do?
- What did I feel?
- What changed in thesis, risk, or emotion?
- What should feed cognition, decision, execution, or evolution?
- Did any signal become a thesis substitute?
- Did any position consume disproportionate attention?
- Did any decision affect unrelated holdings?

## Mixed-Quality Exit Review

Status:

- candidate pending user approval

When an exit happens during emotional pressure, classify it in two separate dimensions:

```yaml
process_quality:
outcome_quality:
thesis_status:
risk_reduction_status:
reentry_allowed:
```

Rules:

- A useful risk reduction can still have compromised process quality.
- A compromised process can still accidentally protect capital.
- If process quality is compromised, re-entry is forbidden until a fresh plan is written.
- If thesis status is unresolved, do not treat the exit as thesis falsification.
