# Execution System

The execution system turns decisions into disciplined behavior.

It does not create thesis.

It enforces:

- plan before action
- no-trade conditions
- sleep risk checks
- signal-to-action discipline
- review after execution

## Purpose

Make the right behavior easier and emotional behavior harder.

## Daily Rhythm

```text
after work = pre-market
before sleep = risk lock
during market = low intervention
morning / daytime = asynchronous review
weekend = deep review and research
```

## Files

- `daily-operating-loop.md`: practical trading-day loop.
- `weekly-use-cases.md`: common weekly usage patterns and orchestration entrypoints.
- `pre-market.md`: execution-facing pre-market checklist.
- `intraday.md`: low-intervention rules.
- `post-market.md`: review handoff after execution.
