# 2026-07-12 CPI/PPI 前风险决策：认知系统应用记录

> 模式：observation / research。账户事实、持仓数量、成本、现金和最大可承受损失尚未核对，因此本记录不给出具体仓位百分比或订单。

## 当前问题

在 2026-07-14 CPI 与 2026-07-15 PPI 发布前，是否应主动规避风险；以及如何把 Investing-OS 的认知框架用于真实的每日交易准备。

## 当前建议

不是“事件前全部规避”，而是执行分层风险控制：

1. 数据公布前不新增 AMAT、TSM、MU、COHR、NBIS 等高度相关的 AI/半导体风险；
2. 不在第一轮数据跳动中交易，等待利率、美元、指数和行业相对强弱形成一致解释；
3. 已有仓位不因事件标题自动卖出，但必须先做组合级压力测试；
4. 若压力情景下的损失超过用户当前可承受范围，则应在事件前降低脆弱性，而不是赌数据；
5. 最近亏损较多时，恢复目标优先于回本目标，禁止使用新仓、加仓或杠杆修复近期亏损。

## 用 Reality -> Consensus -> Price 拆解

### Reality

CPI/PPI 是通胀事实的新观测，不直接改变 AI 长期产业现实。它可能改变的底层链条是：

```text
通胀持续性
-> Fed 路径
-> 长端利率
-> 成长股估值
```

因此第一判断应是影响 PE 还是 EPS。默认首先影响 PE；只有融资成本、企业资本开支或终端需求持续改变时，才进一步修改产业 thesis。

### Consensus

数据的重要性不只在高或低，而在相对市场预期的偏差，以及市场如何解释核心通胀、商品/服务分项和生产端传导。当前仍缺少本轮正式 consensus package，不能只凭“CPI 较高/较低”下结论。

### Price

数据后需同时观察：

- 美国 2Y/10Y 收益率；
- 美元；
- QQQ 相对 SPY/IWM；
- SMH/SOXX 相对 QQQ；
- AMAT/TSM/MU/COHR/NBIS 的相对强度，而非单看涨跌。

价格第一跳只代表即时重定价，不自动证明 Reality 改变。

## 三种情景与权限

### 情景 A：通胀低于预期，利率回落

- 允许继续观察建仓候选；
- 不追第一跳；
- 等第二阶段承接和公司事实验证后，才讨论升级 TSM/AMAT。

### 情景 B：通胀高于预期，2Y/10Y 与美元同步上升

- 保持无新增风险；
- 高估值、高波动、高融资需求标的优先受限；
- 不把下跌自动解释为更便宜；
- 先判断只是 PE 压缩，还是已经通过 capex/融资链影响 EPS。

### 情景 C：数据与价格反应矛盾

- 不交易解释冲突；
- 标记为 `interpretation_pending`；
- 等 PPI、债券市场和第二日价格共同确认。

## 五个标的的事件前处理

| 标的 | 数据前状态 | 原因 |
|---|---|---|
| TSM | `event_wait` | CPI/PPI 后紧接财报，双重事件风险，不提前追建 |
| AMAT | `pullback_wait` | 高相关成长估值风险，等利率与 TSM 事实交叉验证 |
| MU | `hold_no_add`（若确为普通股且已持有） | thesis 与价格路径分开，不在高波动期补仓 |
| COHR | `risk_review / no_add` | 价格结构弱且波动高，禁止 repair averaging down |
| NBIS | `observation_only` | 融资与估值对利率更敏感，不升级为建仓候选 |

## 组合级压力测试（账户核对后执行）

需要补齐：

- 每个标的、工具类型和实际仓位；
- AI/半导体合计风险，而非逐票孤立计算；
- 是否含杠杆产品；
- 若相关标的同步下跌一个正常事件波动区间，组合损失是否可接受；
- 该损失是否会诱发补仓、报复性交易或注意力失控。

只有当最后两项答案为“可接受且不会破坏纪律”，才有理由保留完整事件暴露。否则降低风险属于组合约束，不属于宏观预测。

## 这次对认知系统的实际使用

本次不是用框架预测 CPI，而是让框架完成四个动作：

1. 把事件标题下钻到真实传播链；
2. 分开 Reality、Consensus 与 Price；
3. 把公司 thesis 与事件期估值风险分开；
4. 将研究结论转换为权限：数据前不新增、第一跳不交易、冲突时等待、超出承受力时先降脆弱性。

## 下一步

在不要求用户立刻核对全部账户的前提下，下一次对话只需先确认：实际持有的标的与工具、各自大致仓位、是否含杠杆。随后生成一页组合压力表，再决定是否需要在 CPI 前降低已有风险。
