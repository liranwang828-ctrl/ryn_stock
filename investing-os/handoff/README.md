# Handoff

This directory stores structured handoff documents for collaborators and future agents.

Handoffs should make context transferable without turning the project into a loose conversation archive.

## Rule

Every handoff should clarify:

- Current project state
- System purpose
- Boundaries
- User context
- What to inspect next
- What not to change without approval
- Open questions
