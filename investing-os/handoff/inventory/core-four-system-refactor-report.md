## Corrected Model

Trading and research are not the center.

They are nutrient sources.

They feed:

- `cognition/`: self-model, biases, emotions, mistake patterns
- `decision/`: thesis, roles, risks, falsification, watchlist
- `execution/`: daily operating loop and behavior under market pressure
- `evolution/`: promotion rules, system updates, long-term compounding

Supporting layers:

- `wiki/`: long-term memory
- `system/`: workflows, checks, packets, snapshots, schemas
- `templates/`: structured input forms
- `integrations/`: boundaries with external tools
- `handoff/`: collaboration records

## Next Use

Every meaningful trade, review, or research session should ask:

1. What updates `cognition/`?
2. What updates `decision/`?
3. What updates `execution/`?
4. What updates `evolution/`?

If none of these change, the material may remain temporary context.
