# Bias Map

## Purpose

Track recurring cognitive biases as operating risks.

Bias is not a moral failure. It is a predictable failure mode to design around.

## Known Biases

### FOMO

Pattern:

- price moves first
- signal feels urgent
- thesis is created after action

Controls:

- signal-to-action checklist
- prewritten thesis
- no-trade condition when thesis is missing

### Loss Aversion

Pattern:

- initial loss feels unacceptable
- add behavior becomes cost reduction
- trade turns into bailout project

Controls:

- predefined invalidation
- predefined add rule
- attention budget pause

### Signal Equals Thesis

Pattern:

- VWAP / volume / price signal is treated as complete reason

Controls:

- require thesis, trigger, risk, falsification
- signal creates review, not command

### Emotional Spillover

Pattern:

- one stressful trade changes decisions in unrelated holdings

Controls:

- position-role checklist
- journal review
- separate risk management from thesis change

### Recent Profit Overconfidence

Pattern:

- recent gains are interpreted as improved skill too quickly
- profits from market beta, one large winner, or luck are mistaken for durable process edge
- confidence rises faster than rule discipline

Controls:

- decompose profits into skill / beta / luck / one-large-winner before sizing up
- no leverage increase after a profit streak without written review
- require tactic evidence across market regimes

### Regime Transfer Error

Pattern:

- a tactic that worked in a supportive market is reused during broad risk-off
- the user assumes the same RS / rebound behavior should continue even as QQQ, sector, and VIX deteriorate

Controls:

- market-context gate before short-term tactics
- tactic disabled during high-volume QQQ / sector selloff or sharp VIX rise
- backtest tactic by market regime before promotion

### Thesis-Instrument Fusion

Pattern:

- a broad thesis feels valid
- the user then treats a leveraged instrument as if it were equivalent to the thesis
- when the position loses, thesis belief makes the instrument harder to exit

Controls:

- separate thesis validity, underlying relative strength, and instrument suitability
- leveraged products require separate holding-period, path-risk, and max-loss checks
- a thesis can remain valid while the instrument is invalid

## Update Rule

Add a bias only when it appears in actual trading, research, or review.
