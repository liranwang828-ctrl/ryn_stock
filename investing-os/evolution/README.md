# Evolution System

The evolution system turns experience into a better operating system.

It is the compounding loop.

## Purpose

Make trading and research feed cognition instead of disappearing as isolated events.

## Core Loop

```text
trade / research
|
review
|
pattern extraction
|
cognition update
|
decision update
|
execution update
|
principle / checklist / dossier / snapshot candidate
```

## Files

- `learning-loop.md`: how experience becomes system improvement.
- `promotion-rules.md`: when observations become principles, cases, checklists, or dossiers.
- `experience-output-map.md`: where outputs from orchestrated workflows should land.
- `system-update-log.md`: log of structural system changes.
