# Learning Loop

## Purpose

Define how research and trading feed the four core systems.

## Trading Nutrients

Trading provides:

- action quality
- emotional data
- risk data
- attention data
- thesis validation or falsification
- execution drift

Feeds:

- `cognition/`: bias, emotional pattern, mistake pattern
- `decision/`: thesis, role, risk, falsification updates
- `execution/`: checklist and workflow updates
- `evolution/`: principles, cases, runtime parameter candidates

## Research Nutrients

Research provides:

- worldview refinement
- industry structure
- company value capture
- valuation assumptions
- falsification evidence
- open questions

Feeds:

- `cognition/`: better mental models
- `decision/`: thesis and watchlist updates
- `execution/`: pre-market context
- `evolution/`: methodology and dossier improvements

## Stock Team Nutrients

`stock_team` provides:

- reports
- pre-market context
- post-market review material
- runtime alerts
- data and calculations

Feeds through:

- `system/data/packets/`
- `templates/packet-review.md`
- `system/workflows/packet-absorption.md`

## Rule

No nutrient goes directly to action.

It must pass through cognition, decision, execution, or evolution.
