# Knowledge Wiki

The wiki is the long-term memory layer.

Wiki stores knowledge.

Agents retrieve context as needed.

## Sections

- `inbox/`: temporary landing zone for imported source assets
- `principles/`: durable investing principles
- `methodologies/`: research methods and mental models
- `industries/`: industry research
- `companies/`: company dossiers
- `historical-cases/`: historical structures and analogies
- `journals/`: investment journals
- `sources/`: stable information sources

## Import Rule

External material enters `wiki/inbox/` first.

It becomes permanent wiki knowledge only after:

- source metadata is preserved
- WHY alignment is checked
- the content is rewritten into the correct durable format
- unclear destinations are resolved
