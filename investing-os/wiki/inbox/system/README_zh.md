# 个人交易系统 Wiki

日期：2026-06-03

这个 wiki 的目的不是把交易机械化，而是把你的判断、纪律、复盘经验和 AI 协作方式沉淀成一个可持续更新的系统。

使用原则：

- 你保留最终交易判断权。
- AI 先读 wiki，再给交易辅助。
- 新经验不要全写成长文，只更新对应原则、案例或待验证任务。
- 规则必须能追溯到案例或验证假设。
