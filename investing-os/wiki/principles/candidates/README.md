# Principle Candidates

This directory stores principle candidates extracted from journals, cases, packet reviews, and post-market reviews.

Candidates are not active principles.

They should not receive `PRIN-*` IDs until promoted.

Use:

- `templates/principle-candidate.md`
- `system/workflows/journal-to-principle-promotion.md`

## Promotion Rule

A candidate can become active only after review confirms:

- repeatable pattern
- WHY alignment
- clear trigger conditions
- clear forbidden behavior
- falsification or revision conditions
- drift risk
- source journal or case
