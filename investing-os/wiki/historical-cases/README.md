# Historical Cases

Historical cases are used to study structure, not to copy prices.

Focus on:

- Technology adoption curves
- Capital cycles
- Bubble and crash mechanics
- Monopoly formation
- Supply-chain shifts
- Valuation regime changes

## Naming

Use:

```text
CASE-[number]-[english-short-name].md
```

Example:

```text
CASE-001-cohr-profit-taking.md
```

## Required Structure

Use `templates/historical-case.md`.

A case must separate:

- facts
- decision context
- subjective psychology
- objective audit
- missed signals
- principle updates
- system updates

## Rule

Historical cases should improve future judgment.

They should not be used to mechanically copy price patterns.
